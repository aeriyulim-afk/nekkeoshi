NEKKEOSHI — A LITERARY ARCHIVE

FILES
- index.html: page structure and content
- style.css: visual design, responsive layout, animations
- script.js: story data, search/filtering, details popup, random story, saved shelf, and navigation behavior

HOW TO OPEN
1. Extract the ZIP file into a folder.
2. Keep index.html, style.css, script.js, and README.txt together in that folder.
3. Double-click index.html to open it in a modern browser.

FEATURES
- Responsive Home, The Archive, Dark Archive, and About sections
- Open Graph and X/Twitter Card metadata for richer link previews
- Active navigation underline while scrolling
- Search and fandom/status filters
- Featured story cards made entirely with typography and CSS (no cover images needed)
- Surprise Me random-story button
- Story detail popups with AO3 links
- Save stories to a browser-local wishlist using localStorage
- Automatic catalog statistics

NOTES
- The saved wishlist is stored in the current browser on the current device. It does not sync between devices and may be cleared if browser data is removed.
- Google Fonts and the existing background image use internet connections. The site itself can still open locally, but those external assets may not load offline.
- Review all story descriptions and metadata before publishing to ensure they are accurate and current.
- Social preview cards use the existing hosted library background image. Some apps cache link previews, so changes may not appear immediately.
- If you later want a custom thumbnail with the Nekkeoshi title, use a publicly hosted image URL and update both og:image and twitter:image to that full URL.
